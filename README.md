# ST77916 LVGL Demo

An embedded UI demo for the **ESP32-S3** driving a **ST77916 QSPI 360×360 round display** with **CST816S capacitive touch**, built with [LVGL 8.3](https://lvgl.io) and the [ESP32_Display_Panel](https://github.com/esp-arduino-libs/ESP32_Display_Panel) library.

![Build](https://github.com/kongdayan/ST77916_LVGL_DEMO/actions/workflows/build.yml/badge.svg)

---

## Hardware

| Component | Details |
|-----------|---------|
| MCU | ESP32-S3 (DevKitC-1) |
| Display | ST77916 · 360×360 · QSPI 4-line |
| Touch | CST816S · I2C |
| Backlight | PWM via LEDC |

### Pin Configuration (`pincfg.h`)

| Signal | GPIO |
|--------|------|
| Backlight (PWM) | 15 |
| Display RST | 47 |
| Display CS | 10 |
| Display SCK | 9 |
| Display DATA0–3 | 11–14 |
| Touch SCL | 8 |
| Touch SDA | 7 |
| Touch INT | 41 |
| Touch RST | 40 |

## Prerequisites

### Toolchain

Install **PlatformIO** (CLI or IDE extension):

```bash
pip install platformio
```

> The project uses the [pioarduino](https://github.com/pioarduino/platform-espressif32) platform to pull **Arduino ESP32 3.1.1** (ESP-IDF 5.3), which is required by ESP32_Display_Panel v1.x. The official `espressif32` PlatformIO platform does not yet ship Arduino 3.x.

### Arduino IDE (optional)

Install **Arduino ESP32 core ≥ 3.1.0** via Boards Manager, then add these libraries via Library Manager:

| Library | Version |
|---------|---------|
| ESP32_Display_Panel | v1.0.4 |
| ESP32_IO_Expander | v1.1.0 |
| esp-lib-utils | v0.2.0 |
| lvgl | 8.3.11 |

## Build

### PlatformIO (recommended)

```bash
# Clone the repo
git clone https://github.com/kongdayan/ST77916_LVGL_DEMO.git
cd ST77916_LVGL_DEMO

# Build only
pio run

# Build and flash
pio run --target upload

# Open serial monitor (115200 baud)
pio device monitor
```

Dependencies are fetched automatically from `platformio.ini` on first build.

### Arduino IDE

1. Open `ST77916_LVGL_DEMO.ino` in Arduino IDE 2.x.
2. Select board: **ESP32S3 Dev Module**.
3. Set **USB CDC On Boot** → **Enabled**.
4. Click **Upload**.

## Configuration

### LVGL (`lv_conf.h`)

Only the widgets used by this project are enabled to reduce binary size:

**Enabled:** ARC, BAR, BTN, CHECKBOX, IMG, LABEL, SLIDER, SWITCH, CALENDAR, SPINNER, TABVIEW, BTNMATRIX (required by CALENDAR), FLEX layout, GRID layout, Default theme.

**Disabled:** DROPDOWN, ROLLER, TEXTAREA, KEYBOARD, CHART, METER, TABLE, SPINBOX, MENU, and all demo/benchmark widgets.

### Display Driver (`scr_st77916.cpp`)

Key parameters you may need to adjust:

```cpp
#define TFT_SPI_FREQ_HZ (50 * 1000 * 1000)  // QSPI clock — lower if signal integrity issues
const size_t lv_cache_rows = 72;             // LVGL draw buffer height (rows)
```

Rotation can be set at runtime:

```cpp
setRotation(0);  // 0 = default, 1 = 90°, 2 = 180°, 3 = 270°
```

Backlight control:

```cpp
screen_switch(true);      // on / off
set_brightness(80);       // 0–100 %
```

## CI/CD

Every push and pull request to `main` triggers a GitHub Actions build that:

1. Restores PlatformIO package cache (keyed on `platformio.ini`)
2. Compiles the firmware with `pio run`
3. Uploads `firmware.bin` + `firmware.elf` as a workflow artifact (retained 30 days)

The build badge at the top of this README reflects the current `main` branch status.

To flash a CI-built binary manually:

```bash
esptool.py --chip esp32s3 --port /dev/ttyUSB0 write_flash 0x10000 firmware.bin
```
